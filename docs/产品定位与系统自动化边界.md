## 产品定位与系统自动化边界

### 1. 产品定位

SrilankaOL 是一套用于支持主持人裁决型多人国家角色扮演游戏的网页管理工具。

系统的主要目标是：

- 保存游戏世界状态；
- 管理玩家提交的行动；
- 整理主持人裁决所需的信息；
- 自动执行简单且明确的规则；
- 记录主持人的最终裁决；
- 向玩家发布统一的回合结果。

系统不以自动模拟全部国家行为和国际局势为目标。

### 2. 主持人的核心地位

主持人仍然负责：

- 操作 NPC 国家；
- 判断复杂外交行为；
- 协商自定义政策效果；
- 处理特殊政治和继承事件；
- 调整系统建议；
- 编写或确认叙事结果；
- 处理规则未覆盖的特殊情况。

系统只为主持人提供信息、计算和操作界面，不取代主持人的最终裁决权。

### 3. 自动处理规则

系统应自动处理结果客观、计算简单且频繁发生的内容，包括：

- 数值增减；
- 政策槽位检查；
- 外交关系额度检查；
- 政策锁定回合；
- 外交行动冷却时间；
- 条约持续时间；
- 单位移动点消耗；
- 资源和财政结算；
- 已确认效果的持续执行；
- 状态与历史记录。

这类规则应具有明确输入和确定结果，不需要主持人逐次判断。

### 4. 辅助裁决规则

系统可以对复杂行动提供裁决辅助，包括：

- 汇总 NPC 外交回应因素；
- 展示双方实力、关系、条约和战争状态；
- 根据预设规则计算建议值；
- 生成可选结果；
- 生成政策成本和效果建议；
- 提示可能触发的后续事件；
- 生成叙事文本草稿。

主持人可以接受、修改或拒绝系统建议。

系统应记录建议结果与主持人最终结果之间的差异。

### 5. 人工决定内容

以下内容原则上不要求首版自动判定：

- 玩家之间的外交协商；
- NPC 对复杂或自由文本提议的回应；
- 自定义政策的最终效果；
- 复杂继承争议；
- 特殊王室和共主事件；
- 国家战略意图；
- 无法量化的政治利益；
- 特殊剧情结果。

系统只需要提供提案、讨论、确认和记录流程。

### 6. 标准行动与自由行动

外交、政策和其他系统可以同时支持两种行动：

#### 6.1 标准行动

标准行动拥有预设条件和效果，例如：

- 提议联盟；
- 请求军事通行；
- 改善关系；
- 保证独立；
- 宣战；
- 提出和平协议。

标准行动可以进行较多自动检查和计算。

#### 6.2 自由行动

玩家可以提交自由文本行动，例如：

- 提出特殊外交交换；
- 设计新的政治协议；
- 要求外国支持继承人；
- 组织秘密联合行动。

自由行动由主持人裁决。系统只保存提议内容、参与方、协商过程和最终结果。

### 7. NPC 外交判定边界

NPC 外交可以保留接受倾向机制，但不要求所有外交行为都建立完整公式。

处理方式如下：

- 简单标准行动可以使用固定接受倾向规则；
- 复杂标准行动可以由系统展示因素并由主持人确认；
- 自由外交行动直接由主持人处理；
- 玩家国家之间不使用自动接受判定。

因此，“接受倾向大于 0 自动成功”只适用于已经配置确定公式的标准外交行动。

### 8. 联盟机制示例

联盟在首版中只需记录以下核心规则：

- 联盟表示军事互助和共同防御关系；
- 联盟成立后占用双方各自的一个外交关系额度；
- 同一国家之间的其他占额关系不再额外占用额度。

当盟友成为防御方时：

1. 系统自动生成对所有盟友的参战请求；
2. 玩家盟友自行决定是否参战；
3. NPC 盟友由主持人决定，或使用已配置的标准判定；
4. 拒绝履行防御义务时，系统提示解除联盟和降低关系；
5. 主持人确认后应用结果。

当盟友作为进攻方时：

1. 进攻方可以选择邀请哪些盟友；
2. 进攻方可以附加利益、领土、资源或其他承诺；
3. 玩家盟友自行决定；
4. NPC 盟友由主持人根据关系、利益和战争风险裁决；
5. 系统记录参战承诺和交换条件。

系统不需要自行理解复杂的国际战略，也不需要自动计算所有国家是否应当参战。

### 9. 功能设计原则

设计每项机制时，只需要回答以下问题：

1. 系统需要保存什么状态；
2. 玩家能够提交什么操作；
3. 哪些条件可以自动检查；
4. 系统需要向主持人展示什么信息；
5. 主持人确认后系统应用什么结果。

若某项内容无法通过上述结构清晰表达，则应保留为主持人自由裁决，而不是继续增加复杂公式。

### 10. 首版开发原则

首版优先实现：

- 数据管理；
- 玩家行动提交；
- 主持人裁决工作台；
- 状态与关系展示；
- 简单确定性计算；
- 结果发布；
- 修改和回滚记录。

首版不实现：

- 完整 NPC 国家人工智能；
- 自动国家战略规划；
- 全自动外交谈判；
- 完整历史继承模拟；
- 对所有自由文本行动进行自动规则判定；
- 与商业大战略游戏相当的规则覆盖范围。
