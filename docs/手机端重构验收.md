# 手机端工作区重构

2026-10-29，基于 `b28a3dd`。目标是让手机完成现有桌面端任务：一个主要工作区、明确的上下层返回入口、输入时优先保留正文与操作按钮。

## 功能对应

| 桌面功能 | 手机入口与操作 |
| --- | --- |
| 地图、图层、搜索、图例、历史 | 地图页；保留全部工具，增加双指缩放和平移 |
| 地块、城市、军队、省份等详情 | 地图中打开完整详情页，关闭后回到原地图 |
| 地图编辑、开局布置、探索揭示 | 地图工具；选区地图与设置表单可切换，已选地块和表单保留 |
| 即时更正、军队移动 | 地图页；仍须填写更正原因，移动时显示目的地选择地图 |
| 玩家政策 | 底部政策；完整分项编辑、草稿、正式提交、AI、关联地图和讨论 |
| 主持人审核 | 底部审核；队列进入详情，返回保留审核意见与政策解释 |
| 结算、账单、战斗、资源与状态变动 | 底部结算；列表与详情切换，反馈前置、继续下一项、保存和发布确认 |
| 回合结果、历史结算、更正 | 底部结果/结算；沿用原有读取、更正与权限逻辑 |
| 消息与会谈 | 底部消息；会话列表/详情、新建会谈、联系主持人或玩家、关联政策、消息草稿 |
| 国家、经济与贸易、军事、政府、外交 | 全部功能；每项有独立入口，编辑表单与数据权限共用桌面组件 |
| 剧本、通用与经济规则 | 全部功能 → 剧本与规则 |
| 回合事务 | 全部功能 → 回合事务，完整宽度查看 |
| 开局检查、成员、分配国家、结束游戏 | 全部功能 → 开局准备/本局管理 |
| 国家切换、玩家视角预览 | 全部功能顶部；切换受原有编辑状态限制 |
| 账号、退出、全局 AI 设置 | 顶部账号与设置；全局 AI 仍仅系统管理员可管理 |
| 多游戏与历史游戏 | 顶部游戏选择，沿用游戏与账号的草稿隔离 |

## 布局与数据边界

- 760 像素以下，或宽度不超过 1000 且高度不超过 500 的横屏使用手机布局；扩大视口自动恢复桌面分栏。
- 隐藏列表、切换功能和打开目录不卸载已经打开的业务组件，避免在导航过程中清空输入。
- Visual Viewport 用于键盘与地址栏占用空间；页面放大时不强制改变应用大小。安全区来自浏览器环境变量。
- 主要触控目标至少 44 像素，表单输入字号 16 像素。宽数据表保留局部横向滚动。
- 回合推进、权限、正式提交、发布确认、审核规则均复用已有业务逻辑。
- 本轮提供页面内返回路径；浏览器 URL 路由、刷新恢复工作位置仍是独立待办。

## 验证记录

- 新增 9 项角色导航、审核/消息/结算返回保稿、双指手势误触保护、地图选区切换、可视区域缩放及监听清理回归测试；全量前端 226 项测试通过，类型检查、生产构建与 ESLint 通过。
- 浏览器使用本地隔离接口与真实组件，在 390×844 检查了主持人导航、审核列表/详情、全部功能、消息、结算队列与下一项入口；390×480 检查了输入区、发送按钮与完成输入。模拟数据未连接正式游戏。
- 验证途中本地浏览器被 Work 设置关闭，后续修正以自动测试、类型检查和生产构建检查；最终视觉复查、320 像素窄屏与横屏尚未完成。
- 尚未在真实手机上验证系统软键盘、地址栏动态伸缩、刘海安全区与双指手势。浏览器缩小视口不能替代实机键盘验证。
