# 地图生成与快速布置

2026-10-29。目标是让主持人先取得可用的地理底图，再按剧本调整，减少逐格设置。

## 采用的思路与取舍

参考《文明6》[官方手册的高级建图选项](https://downloads.2kgames.com/civilization/vi/manuals/eu/CIV_VI_25TH_ONLINE_MANUAL_ENG.pdf)，采用地图类型、大小、少量地形参数和随机种子的交互方式。生成算法为本项目独立实现，预览与服务器共享同一个确定性函数。

仅使用当前已有的平原、丘陵、山地、森林、水域五类地形。海平面控制陆水比例；湿度控制森林比例；地质年龄控制山地和丘陵比例。不增加资源、自然奇观、温度、灾害或 AI 生成步骤，也不增加没有规则支撑的选项。

- 盘古大陆：以一片主要陆地为主，适合陆上往来。
- 多大陆：海峡分隔主要陆地，适合跨海关系。
- 群岛：分散的小岛，适合群岛剧本。
- 内海：外围陆地环绕中部水域。
- 空白地图：保留原有全平原手动布置方式。

自动划分国家默认关闭。开启后，各国至少获得一块陆地，采用分散起点与陆地扩展，分离岛屿归到邻近起点；水域保持无主。它是剧本布置的起点，不能保证国土面积、经济条件与军事条件平衡，不会自动创建城市、军队、省份或资源。

## 操作路径

1. 主持人在开局准备中进入地图，选择“布置地图”。
2. 未创建地图时直接选择生成方式、地图大小（小型 24×16、标准 40×28、大型 64×44，或自定义 1–100 行列）、海平面、湿度、地质年龄与种子。
3. 预览即时显示五类地形数量；可以“换一张预览”，也可输入同一种子复现。开启自动划分国家后，可以切换国家划分预览。
4. 点击“创建此地图”才保存。预览不写服务器、不向玩家揭示情报。
5. 已创建但尚未布置内容的开局地图，可展开“自动生成地形”重新预览、确认覆盖。尺寸保持不变，保留地块 ID。
6. 局部修整使用“笔刷添加选区 / 笔刷擦除选区”，支持单格、7 格、19 格、37 格笔刷。拖动涂选不直接修改地图；在“布置地块”填写地形、归属或地区后，点击“应用到所选地块”。一次最多 2500 格，原有矩形选区继续可用。
7. 桌面与手机共用这些功能；手机在选区地图与设置表单之间切换，选区和表单保留。

## 保存与保护

- 自动创建/重新生成仅限主持人、管理员的第一回合开局准备阶段；运行中的游戏不能整体重新生成。
- 重新生成前检查地图修订号，其他页面修改后拒绝覆盖，重新读取状态供主持人检查。
- 已有国家归属、占领、地区关联、城市、军队、道路、备注或国家已知情报时拒绝整体重新生成。继续用原有批量编辑与即时更正流程。
- 保存生成参数、地块变化前后快照、世界版本和地图记录。生成操作在单个数据库事务中完成，非法国家或失败写入不会留下半张地图。
- 旧的空白地图创建 API 保持兼容；地图生成本身不需要新表；本次发布同时包含地块状态结构升级 `030_tile_tags.sql`，由启动部署流程执行。

## 验证范围

新增 17 项 API/生成算法测试和 5 项前端测试。全量前端 231 项、API 78 项、配置 5 项、数据库 10 项与部署更新 9 项测试通过；类型检查、全项目生产构建和 ESLint 通过。测试覆盖种子复现、地形参数效果、所有地图类型与国家划分、坐标和尺寸边界、预览与数据库结果一致、权限与 HTTP 参数校验、失败回滚、修订冲突、保护已有内容、生成确认与笔刷选区。

另用 10 组固定种子检查地理轮廓：盘古大陆最大陆块占陆地 97%–100%；多大陆均有两个主要陆块；群岛有 10–12 个陆块；内海外围陆地保持连通。性能抽查本地 100×100 地图加 20 国划分约 89 毫秒，非手机性能承诺。

本地使用 PGlite 加载全部真实迁移执行服务 SQL，不连接正式存档。另输出固定种子的四类地图示例检查地形轮廓。本轮浏览器交互仍受 Work 设置限制，尚未复查最终页面布局和实机触控。
