# 账号管理与登录保护

日期：2026-10-19。用于小组内由主持人组织的在线试玩。

## 页面使用

- 自己修改密码：右上角“账号”，填写当前密码、新密码与确认。成功后所有设备的旧登录都失效，需要重新登录。新密码至少6个字符，支持中文和短句；原有密码继续正常登录。2026-10-22 已将注册、登录、改密、重置及首位主持人初始化统一为6字符下限。
- 玩家忘记密码：联系主持人，确认是本人请求后，主持人在“本局管理”的成员行选择“重置登录”，填写协助原因和自己的当前密码，生成一次性重置码。玩家在登录页选择“使用重置码”，填写用户名、码和新密码，再正常登录。
- 邀请注册：“本局管理 → 生成注册邀请码”，验证主持人当前密码后生成。新同学在注册页填写邀请码，注册完把用户名交给主持人添加成员、分配国家。邀请码不自动授予游戏权限。
- 协助记录：“本局管理 → 账号协助记录”，按本局查看生成、使用及重置记录；不包含密码、码或登录令牌。

重置码30分钟内有效，邀请码7天内有效，均只能使用一次，关闭生成结果后不能重新读取明文。重新生成某人的重置码会废止其旧码；生成本身不修改密码，也不踢出玩家。改密同时废止涉及本人和由本人签发的未使用重置码，以及本人签发的未使用邀请码。密码表单、码和主持人的验证密码都不保存到本地草稿或地址栏。修改密码不删除同账号已有的政策、消息和结算本地草稿。

主持人只能协助当前未结束游戏中的活动玩家／观察者，不能重置主持人或系统管理员。使用主持人生成的码时重新检查本局状态、主持人权限和目标成员身份；移除成员、提升权限、结束游戏后，原码失效。游戏归档不影响账号本人改密。

## 维护者操作

`REGISTRATION_MODE` 在 API 环境中配置：`open` 自由注册、`invite` 邀请注册、`closed` 关闭注册。未配置时开发／测试环境默认开放，生产默认关闭；已有账号均可登录。当前本地试玩已设为 `invite`。修改环境后重启 API。

主持人本人无法登录时，由有数据库维护权限的人核实本人请求，在项目根目录运行：

```powershell
pnpm.cmd --filter @srilanka/api account:reset --username 用户名 --reason "本人请求恢复主持人登录"
```

命令使用当前 `DATABASE_URL`（或项目 `.env`），只为现有活动账号生成30分钟一次性重置码，不直接设置密码。明文仅输出到维护终端，交给本人在网页登录页使用；数据库记录维护恢复原因。执行前核对数据库，勿把终端输出公开。首个正式主持人账号的部署初始化仍属于后续远程部署步骤；不要在生产运行开发种子脚本。

## 已实现的基础保护

- 登录、注册、重置、重新验证密码和生成码分别持久限速。登录同一连接地址与用户名组合15分钟内最多10次；同地址总共最多60次，均计入成功与失败尝试。超限返回429和等待秒数，重启进程不会解除限制。
- 不信任客户端伪造的 `X-Forwarded-For`；当前按连接地址计数。公网反向代理的可信来源配置和实际客户端地址验证留到部署验收。
- 重要操作重新验证当前密码和会话。新密码写入、旧会话撤销、码消费在同一事务中完成；并发重复使用只成功一次。登录与密码修改锁定相同账号，避免旧密码留下新的有效登录。
- 新密码采用 scrypt `N=16384,r=8,p=5`，旧 `p=1` 在正常登录后升级。密码计算采用异步队列并限制并发；接口请求体限制8 KiB。
- 码以安全随机数生成，数据库仅存摘要。新接口响应禁止缓存；日志遮盖密码、码、授权头及会话 Cookie。跨源修改请求拒绝不匹配的 Origin。
- 恢复使用一次性码、有效期、单次消费、恢复后正常登录，参考 [OWASP 密码恢复建议](https://cheatsheetseries.owasp.org/cheatsheets/Forgot_Password_Cheat_Sheet.html)；scrypt 参数参考 [OWASP 密码存储建议](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)。
