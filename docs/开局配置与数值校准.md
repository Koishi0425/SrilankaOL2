# 开局配置与数值校准

第一回合准备页提供“开局资源与平衡试算”。成员分配仍是必需步骤，地图、规则与政府的原设置入口收在“更多开局设置”中。

## 建议流程

1. 添加玩家并分配国家，按剧本准备地图、法定归属与省份产出。
2. 打开“开局资源与平衡试算”，读取服务器当前已保存的配置。
3. 填写目标平均季收入，点击“生成参考经济方案”。生成只修改本页草稿，可展开系数微调。
4. 用“统一初始国库／统一初始人力”一次填写所有国家，再在表格中逐国调整。400 国库、1000 人力只是可修改的试跑示例。
5. 核对季收入、军费、行政费、季净额、人力恢复、四季预测和国家间差异，再保存整批资源与规则。
6. 保存或放弃预算草稿后，按原流程确认开放第一回合。

## 参考方案如何计算

参考方案会为未设置产出的省份拟定基础税收 10、生产 10、人力 100；已有数值或已调整过的省份全部保留。生成后可取消这一项，再更新试算。页面显示保存时将补齐的省份数量，正式保存前不会修改省份。

工具先以单位系数读取真实或拟定的省份产出、自治、法定归属与控制比例、地块修正、现有军队及长期政策，然后校准共同的税收和生产系数，使平均税收与生产收入接近目标，贸易收入另外计算。系数最多保留两位小数，因此实际结果可能偏离目标。

现有部队的维护费目标约为目标总收入的 30%，每国行政费约为目标平均收入的 10%。没有现有部队时，每百人维护费参考值为 1。人力系数参考值为 1；贸易系数保留原值，可单独调整。上述比例是便于试跑的起点，并不等于经过多人对局验证的平衡标准。

地图尚未划分省份、法定归属与控制方不一致、收入系数为零等情况都会使收入为零；工具会提示核对，不会自动创建省份、军队、国家或领土。国家间的原有强弱差异会保留，主持人可在表格和原省份设置中调整。

## 试算与保存

试算复用正式经济结算公式，采用当前保存的世界状态和本页拟定系数，不冻结正式回合快照、不扣费、不生成正式账目。自动经济关闭时，试算显示自动现金流为零，初始资源仍可统一设置。

四季预测保持领土、部队、系数和当前修正不变。它不预测战争、新政策或征募支出，也不推演临时地块修正、长期政策到期。应将它当作静态预算压力检查。

保存仅允许第一回合准备阶段的主持人操作。所有国家余额、经济系数和勾选的空白省份基础值在同一事务中更新，保留资源账目、规则记录与地图修改历史；任何一项失败都会回滚。准备内容被另一窗口修改时拒绝旧版本保存，页面保留当前输入，须重新读取并核对。

全局 AI 配置和 AI 生成不会参与数值校准或保存。
