# 界面体验优化验收

2026-10-21。本轮围绕常用操作调整前端，不修改游戏规则、数据接口、权限或发布流程。

## 使用变化

- 桌面功能面板与地图之间可拖动分栏，保留基本阅读和地图空间；双击或 Home 还原默认宽度，也支持左右方向键微调。当前工作区切换菜单、展开和还原后保留宽度。
- 政策清单可以按标题、国家和类别搜索，筛选待处理、草稿或已处理状态。无匹配项时可清除筛选，当前打开的编辑内容保留。再次点击新建按钮不再清空尚未创建的文字稿。
- 结算清单可搜索国家或标题、只看未填写反馈；完整进度、跳转下一项和保存仍使用全部政策。隐藏列表项不会丢弃其反馈。标题与讨论按钮、地图与起草工具紧凑排列，反馈输入区提前显示。
- 地图的政治、地形和情报模式直接点击切换；保持当前地块选择。搜索结果不再挤占地图高度，支持上下方向键、Escape 返回搜索框，选中结果后焦点回到地图。
- 初始全图随面板和窗口尺寸适配。手动平移、缩放或定位后，调整空间保留当前观察中心；“全图”重新开启适配。
- 从国家经济资料定位地区后，可以返回原经济页及省份选择。窄面板的政策清单与正文上下排列，地图工具不会遮挡打开的功能面板。
- 统一选中、焦点和表单的颜色与间距，沿用简洁的中文界面。
