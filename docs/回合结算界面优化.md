# 回合结算界面优化

2026-10-17。调整界面呈现和操作，不改变规则、接口权限或已发布结算。试玩仍为第 1 年秋季政策提交阶段。

## 阅读顺序

先显示回合公报，再显示本季收支汇总，之后阅读政策结果。主持人可以按国家筛选政策；每项政策的反馈、费用、省份与军队变化、外交和行政结果放在一起。

本季收支以各国国库、人力的净变化及期初 → 期末余额呈现。汇总包括例行经济、手动政策收支和征兵费用，人力不会混入国库。没有取得的资源数据留空，不以零代替。

每季经济明细默认收起。展开后按国家显示收入、支出、常规结余和人力；再展开收支明细，才显示单项金额。只有主持人改过的金额同时显示原计算额和修正原因。依据与修正区域就在对应金额下方，可以再次点同一按钮收起。

例如河谷春季的常规经济结余为 +132.4，修渠费用为 -120，国库本季净变化为 +12.4，余额 1,000 → 1,012.4。修渠政策下面同时显示费用与生产基础 6 → 8，避免把同一件事分散到几个列表。

## 主持人操作

待结算政策按国家排列，显示已填写数量，可以直接跳到下一项未填写政策。政策清单与正文分别滚动，保存和发布按钮保留在下方。

展开经济账单时使用正文区域查看与修正账目，收起后回到政策，不丢失已输入的反馈。发布前核对单独展示，先看净变化；公报、政策反馈和经济明细可继续展开核对，取消时保留原输入。
