- 建立安全共享契约、环境配置、结构化日志和 PostgreSQL 基础包。
- 实现 `/api/v1/health`、`X-Request-Id`、统一响应信封以及 200/503 降级行为。
- 实现 PostgreSQL 迁移表、SHA-256 校验和与事务化 SQL 迁移。
- 提供 PostgreSQL、Redis、对象存储、API、worker、Web 和 Nginx 的 Compose 配置。
- 提供 CI、开发说明、MVP 功能编号和风险清单。

## 待验证

当前 Windows 环境没有 Docker CLI，以下项目不能在本机伪报通过：

1. Compose 配置解析与完整服务启动。
2. API 对真实 PostgreSQL 和 Redis 的健康检查。
3. `pnpm.cmd db:migrate` 在真实数据库上首次执行和重复执行。
4. `@srilanka/api` 真实依赖集成测试。
5. 容器重启后的数据库、Redis 持久化行为。

这些检查已写入 CI；也可以在具备 Docker 的开发机上按 `README.md` 执行。
