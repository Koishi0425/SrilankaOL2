# SrilankaOL 项目风险清单

| 编号     | 风险                       | 影响                   | 当前缓解措施                                                       | 复查阶段 |
| -------- | -------------------------- | ---------------------- | ------------------------------------------------------------------ | -------- |
| RISK-001 | 功能范围持续膨胀           | 无法形成可玩闭环       | 严格按 M0→M6 顺序；专用玩法默认延期                                | 每阶段   |
| RISK-002 | 玩家真实字段泄露           | 严重权限与游戏公平问题 | 后端投影视图；共享契约不导出数据库实体；权限自动测试               | M1、M3   |
| RISK-003 | 多场游戏数据混用           | 跨游戏越权             | 所有业务对象带游戏边界；集成测试覆盖跨游戏 ID                      | M1       |
| RISK-004 | 正式状态部分提交或静默覆盖 | 世界状态不可恢复       | M5 引入事务、变更集、对象版本和幂等键                              | M5       |
| RISK-005 | 地图一次加载过多数据       | 浏览器和接口性能下降   | 按视口和图层增量加载；目标规模性能测试                             | M2、M8   |
| RISK-006 | Redis 故障破坏正式状态     | 游戏数据丢失           | Redis 仅作缓存/队列；正式状态保存在 PostgreSQL                     | M0、M5   |
| RISK-007 | AI 输出越权或不可用        | 秘密泄露或流程中断     | Agent 工具白名单、只生成草稿、完全手工降级                         | M7       |
| RISK-008 | 日志记录连接串或秘密消息   | 敏感信息泄露           | 结构化日志统一脱敏；普通日志禁止完整私密内容                       | M0、M4   |
| RISK-009 | 迁移文件被修改             | 环境数据库结构漂移     | 迁移校验和；已执行迁移只允许新增修正文件                           | M0       |
| RISK-010 | 本地缺少 Docker            | 依赖连通验收不完整     | 静态/注入测试先行；CI 使用真实 PostgreSQL/Redis；补做 Compose 验收 | M0       |
