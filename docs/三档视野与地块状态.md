# 三档视野与地块状态

2026-10-29。按新局规则实现，不提供六档情报的旧局转换。数据库升级只建立新结构和写入约束，不删除、重写旧局存档；旧局不作为新玩法兼容目标。服务器更新自动执行 `030_tile_tags.sql`，用户不需要手动迁移。

## 视野与揭示

| 玩家状态 | 含义 |
| --- | --- |
| 未知 | 不显示地形和附加状态；己方部队的位置仍属于本国信息 |
| 已知 | 已获得的地图资料和上次动态情报；记录不代表当前仍然生效 |
| 可见 | 处在有效视野内，自动更新可观测的动态情报 |

持久化状态为 Unknown、Mapped、Observed 三种；取消传闻、已发现、旧情报档位。一次侦察报告保存为“已知”，不授予持续可见。只有实际控制地块和己方军队周围两格的有效视野产生“可见”。敌军仍按原有估计范围显示，不因可见就公开精确兵力。

主持人只选择“地理信息”“侦察情报”。地理信息更新地图资料，不更新或清空已有动态记录；侦察情报更新观察时的归属、控制、地块状态，可附带敌军报告。清除记录移到高级操作，仍需确认，实际视野内的信息会恢复。

## 状态标签

状态名称、说明和效果相互独立：自定义名称不会被系统当作规则代码。提供遭到破坏、丰收、浓雾预设，数值和观测效果收在高级设置。

- 每个地块可拥有多个状态，同名状态覆盖更新，不重复叠加。
- 本版机械效果：税收贡献百分比、生产收入贡献百分比、遮蔽当地实时观测。也可只写说明作为叙事标记。
- 不同状态的百分比修正相加；每格最终贡献限制为基础值的 0%–400%。例如四格贡献均等的省份，一格生产 -50%，整省生产为原来的 87.5%。
- 不修改省份永久基础值，不重复扣减；人力、贸易与尚未实现的补给系统不自动套用这些修正。
- 状态从开始回合至结束回合均生效；可持续 1–40 回合，或直到主持人移除。
- 开局布置立即生效，持续时间包含当前回合；运行中的直接更正必须进入即时更正并填写原因。
- 普通结算通过“地块状态”添加计划，保存不生效。设置随结算发布，从下一回合开始计算持续时间；移除在发布时生效。本回合已冻结的经济账单不回算。
- 结算可使用政策的地块或省份目标，也可按矩形坐标选择，一次最多 2500 格。变化保留来源、地图修订检查、前后基线和发布记录。

## 信息边界

普通状态随地块动态情报传播，不另设受众菜单。服务器保存真实状态与每个国家的情报快照。真实效果作用于实际结算，玩家地图展示自己掌握的记录。

失去视野后，不同步状态的添加、移除、数值或期限变化，也不在客户端自动过滤过期记录。地理资料保留；上次侦察的状态和观察时间保留，直到再次进入有效视野或主持人提供新的侦察情报。只揭示地理信息不会顺带暴露标签。

浓雾把该地块的实时视野限制到至多“已知”，从未获知的地块仍未知；不凭空授予地理资料。遮蔽只作用于目标地块，不实现阻断后方视线的射线算法。移除或到期后重新计算实际视野。主持人可以通过一次明确的侦察报告提供信息，但不能因此形成持续视野。

标签生效/到期时更新世界和地图版本，使客户端自动刷新；只更新仍有有效视野的情报快照。未知地块和观察者接口不暴露标签；玩家视角预览与玩家接口使用同一份过滤。

经济使用开局/回合开放时冻结的真实状态，按实际拥有且控制的地块贡献折算。地图上的省份估算对玩家使用已掌握的标签，避免经估算接口反向读取隐藏状态。正式账单按真实状态记录实际收入。
